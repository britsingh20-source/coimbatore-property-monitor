# Requirements

## Content rules

- Two topics per day initially; expand to three after 14 clean publishing days.
- Maintain separate Tamil, Hindi and English jobs and publishing histories.
- One official source is mandatory; secondary confirmation is recommended.
- Never describe temporary trial credits as permanently free.
- Display the last verified date for free-plan claims.
- Preserve exact limits: credits, exports, resolution, watermark, signup, card and commercial use.
- Block rumours, waitlists and unavailable regional launches unless clearly labelled.

## Production pack

Each Telegram pack must contain:

1. exact narration script with time bands and performance notes;
2. pronunciation guide;
3. one Gemini cinematic-hook prompt using the creator's approved reference image;
4. one Gemini conceptual B-roll prompt;
5. screen-demonstration shot list;
6. 1080x1920 editing-reference MP4;
7. screen-demo MP4;
8. motion-graphics MP4;
9. SRT captions;
10. thumbnail frame;
11. platform titles, descriptions and exactly three hashtags.

## Final upload validation

- MP4 container; H.264 preferred.
- Vertical 9:16.
- Minimum 720x1280; target 1080x1920.
- Duration 20-180 seconds.
- Audible narration and no clipping.
- No unfinished placeholder cards.
- Job token must uniquely match one pending production job.
- Tool name and language must match.
- Duplicate content hash must not already be published.
- Manual approval remains required during the pilot.

## Operational rollout

- Pilot: one topic, Tamil only, dry-run publishing.
- Phase 2: one topic in three languages.
- Phase 3: two topics per day in three languages.
- Phase 4: optional three topics per day after quality metrics stabilize.
